# Aeleen's — Visual Studio

> *"I photograph what people usually forget to notice."*

## About the Project
Inspired by dark aesthetics, urban environments, solitude, shadows, and the beauty of ordinary moments, this website reflects a personality that values observation, individuality, and simplicity.

It is more than a photography gallery; it is a collection of visual stories told through a minimalist and cinematic perspective.

## Features

**Personalized Design:** A dark, minimalist theme with subtle red accents.
**Photography Gallery:** A curated collection of photographs and visual moments.
**About Section:** An introduction to the philosophy behind the website.
**Favourite Subjects:** A list of photography themes and interests.
**Interactive Styling:** Hover effects and visual transitions.
**Responsive Layout:** A design that adapts to different screen sizes.

## Technologies Used

- HTML — for the structure and content of the website.
- CSS — for styling, layout, animations, and responsive design.
- Git — for version control.
- GitHub — for repository hosting and project management.
- GitHub Pages — for publishing the website.

## Design Philosophy

The website embraces a dark visual identity to create a cinematic and atmospheric experience.

Its design focuses on:

* Minimalism and simplicity.
* Black, charcoal, off-white, and muted red colours.
* Photography with emotional and visual depth.
* Typography that communicates confidence and individuality.
8 The idea that ordinary moments can hold extraordinary meaning.
